# 📊 AI Daily Assistant - Сводка проекта

## Общая информация

**Название:** AI Daily Assistant  
**Версия:** 0.1.0  
**Дата создания:** 28 ноября 2025  
**Язык:** Python 3.9+  
**Лицензия:** MIT

## 🎯 Цель проекта

Создать персонального AI-помощника, который помогает планировать рабочий день, управлять задачами и оптимизировать расписание через удобный Telegram интерфейс.

## 🛠️ Технологии

### Основные
- **Python 3.9+** - Язык программирования
- **python-telegram-bot 20.7** - Telegram Bot API
- **SQLAlchemy 2.0** - ORM для работы с БД
- **Pydantic** - Валидация данных и настройки

### AI/LLM
- **OpenAI GPT-4** - Для AI функциональности
- **Anthropic Claude 3.5 Sonnet** - Альтернативный AI провайдер

### Интеграции
- **Google Calendar API** - Работа с календарем
- **iTop REST API** - Управление тикетами

### Инфраструктура
- **Docker & docker-compose** - Контейнеризация
- **PostgreSQL / SQLite** - База данных
- **Loguru** - Логирование
- **pytest** - Тестирование

- Интернет соединение
