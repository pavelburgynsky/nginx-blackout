# Changelog

Все важные изменения в проекте AI Daily Assistant будут документированы в этом файле.

## [0.1.0] - 2025-11-28

### Добавлено

#### Основной функционал
- 🤖 AI-ассистент с поддержкой OpenAI GPT-4 и Anthropic Claude
- 📅 Автоматическое планирование дня с учетом задач и событий
- ⚡ Оптимизация расписания с умными рекомендациями
- 💬 Telegram бот для удобного взаимодействия

#### Интеграции
- 🗓️ Интеграция с Google Calendar API
  - Получение событий
  - Создание событий
  - Обновление и удаление событий
- 🎫 Интеграция с iTop API
  - Получение тикетов
  - Обновление статусов
  - Статистика по тикетам

#### База данных
- Модели: User, Task, Event, Conversation
- Поддержка SQLite (по умолчанию)
- Поддержка PostgreSQL
- История разговоров с AI

#### Команды бота
- `/start` - Приветствие и начало работы
- `/help` - Справка по командам
- `/plan` - Составление плана на день
- `/tasks` - Просмотр задач
- `/calendar` - События из календаря
- `/itop` - Тикеты из iTop
- `/addtask` - Добавление задачи
- `/optimize` - Оптимизация расписания
- `/settings` - Настройки пользователя

#### Планировщик
- Автоматическое распределение задач по времени
- Учет приоритетов задач
- Автоматические перерывы
- Обеденное время
- Анализ загруженности

#### Документация
- README.md - Основная документация
- INSTALL.md - Подробная инструкция по установке
- QUICKSTART.md - Быстрый старт
- Комментарии в коде

#### Развертывание
- Docker и docker-compose
- Скрипт автоматического запуска (run.sh)
- Пример systemd service
- .env.example с примерами настроек

#### Тесты
- Тесты для планировщика задач
- Тесты для оптимизатора расписания
- Базовая инфраструктура для pytest

### Технические детали

- Python 3.9+
- Асинхронная архитектура
- Логирование с loguru
- Конфигурация через Pydantic
- Type hints во всем коде
