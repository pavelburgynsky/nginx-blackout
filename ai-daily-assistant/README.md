# 🤖 AI Daily Assistant

Персональный AI-помощник для планирования дня и управления задачами через Telegram.

## 🎯 Возможности

- 📅 **Планирование дня** - автоматическое составление оптимального плана работ
- 🗓️ **Интеграция с Google Calendar** - синхронизация событий и встреч
- 🎫 **Интеграция с iTop** - работа с тикетами и задачами из системы управления IT-услугами
- 🤖 **AI-ассистент** - помощь в решении различных задач с использованием GPT-4 или Claude
- ⚡ **Оптимизация расписания** - умные рекомендации по распределению задач
- 💬 **Telegram интерфейс** - удобное общение через мессенджер
- 📊 **Аналитика** - статистика по задачам и продуктивности

## 🛠️ Технологии

- **Python 3.9+**
- **python-telegram-bot** - для работы с Telegram API
- **SQLAlchemy** - ORM для работы с базой данных
- **OpenAI API / Anthropic Claude** - для AI функциональности
- **Google Calendar API** - для интеграции с календарем
- **iTop REST API** - для работы с тикетами

## 📦 Установка

### 1. Клонирование репозитория

```bash
git clone <your-repo-url>
cd ai-daily-assistant
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Отредактируйте `.env` файл и заполните необходимые параметры:

```env
# Telegram Bot
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_ADMIN_IDS=your_telegram_id

# AI Provider (выберите openai или anthropic)
AI_PROVIDER=anthropic
ANTHROPIC_API_KEY=your_anthropic_key_here

# Или для OpenAI:
# AI_PROVIDER=openai
# OPENAI_API_KEY=your_openai_key_here

# Google Calendar (опционально)
GOOGLE_CALENDAR_CREDENTIALS_FILE=config/google_credentials.json

# iTop (опционально)
ITOP_URL=https://your-itop-instance.com
ITOP_USERNAME=your_username
ITOP_PASSWORD=your_password

# Database
DATABASE_URL=sqlite:///./ai_assistant.db
```

### 5. Создание Telegram бота

1. Найдите [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота
4. Вставьте токен в `.env` файл

### 6. Настройка Google Calendar (опционально)

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте новый проект
3. Включите Google Calendar API
4. Создайте OAuth 2.0 credentials
5. Скачайте JSON файл и сохраните как `config/google_credentials.json`

### 7. Настройка iTop (опционально)

Если вы используете iTop, укажите URL вашего экземпляра и учетные данные в `.env` файле.

## 🚀 Запуск

```bash
python main.py
```

После запуска бот будет доступен в Telegram. Найдите его по имени, которое вы указали при создании, и отправьте `/start`.

## 📱 Команды бота

- `/start` - Начать работу с ботом
- `/help` - Показать справку
- `/plan` - Составить план работы на день
- `/tasks` - Показать список задач
- `/calendar` - Показать события из календаря
- `/itop` - Показать тикеты из iTop
- `/addtask <название>` - Добавить новую задачу
- `/optimize` - Проанализировать и оптимизировать расписание
- `/settings` - Показать настройки профиля
